CLAUDE BUDDY 1.3 - QUICK START
==============================
A curly-maned lion who sits on your taskbar with Claude inside.
Full guide: open "Assistail Guide.html" in this folder
(also available later from the menu: Help & user guide).

REQUIREMENTS
  - Windows 10 or 11 (64-bit)
  - Claude Code CLI installed and signed in (run `claude` once in a terminal)
      https://claude.com/claude-code
  - A Claude account with Claude Code access (no separate API key needed)
  - Optional: Windows Terminal (otherwise Command Prompt is used)
  .NET is bundled. No admin rights needed.

INSTALL
  1. Unzip this folder (right-click the zip > Extract All).
  2. Double-click Install.cmd.
     If "Windows protected your PC" appears: More info > Run anyway.
  3. The lion appears on your taskbar and asks for a name.

USE
  Click the lion              chat (opens beside him)
  Right-click the lion        menu: send away / call back, rename, size, model, ...
  Drag the lion               move him along the taskbar
  Right-click > Tricks        jump, wave, chase the pointer, play with a butterfly, ...
  Right-click > Say something  he says it in a speech bubble
  Ctrl+Alt+Space (anywhere)   chat
  Ctrl+Alt+T (anywhere)       next trick (each press = the next one)
  Right-click > Shortcuts     change these shortcuts
  Type "go away"/"come back"  in the chat to send him off or call him back
  Right-click in a folder     "Open Claude Code here"
                              (Windows 11: under "Show more options", or Shift+Right-click)

UNINSTALL
  Settings > Apps > Installed apps > Assistail > Uninstall
