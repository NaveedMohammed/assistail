1. Requirements

WhatDetails
Windows 10 or 11, 64-bitRequired Built and tested on Windows 11. Windows on ARM should work through Windows 11's built-in emulation, but hasn't been tested.
Claude Code CLIRequired Quick chat and “Open Claude Code here” both run the claude command. Install it from claude.com/claude-code, then open a terminal, run claude once and sign in.
A Claude account with Claude Code accessRequired A paid Claude plan or an Anthropic Console (API) account, the same one you use with Claude Code. Quick chat counts against that account's usage limits. No separate API key is needed.
Internet connectionRequiredNeeded to talk to Claude.
Windows TerminalOptional Claude Code opens in Windows Terminal if it's installed (it comes with Windows 11), otherwise in Command Prompt.
.NET Desktop Runtime 8 (or newer)Required Microsoft's free runtime that Assistail runs on. Many PCs already have it. If yours doesn't, the installer offers to download it from Microsoft and install it (Windows asks for permission once, for Microsoft's installer). Keeping it separate makes the Assistail download much smaller.
Admin rightsNot neededAssistail installs for your user account only. (Only Microsoft's .NET installer needs permission, and only if .NET isn't there yet.)

Resources: about 15 MB of disk space (plus the .NET runtime). About 90–150 MB of memory with the lion on screen, a little more while the chat is open. CPU: about 1% of one processor core while he's active, about 0.7% when he's been left alone for 30 seconds (he animates more gently), and zero while the PC is locked or the screen is off (he pauses). Short bursts when he switches animations or you send a chat message.

2. Installing

  1. Download Assistail-x.y.z.zip from the releases page and unzip it: right-click → Extract All…. Don't run the installer from inside the zip.
  2. Open the extracted folder and double-click Install.cmd.
  3. If Windows shows “Windows protected your PC”, click More info → Run anyway. This appears because the app isn't code-signed by a publisher, which is normal for a personal tool.
  4. If the .NET Desktop Runtime isn't installed yet, the installer offers to get it from Microsoft. Answer y and accept the Windows prompt.
  5. Answer y or n when asked whether to start Assistail when you sign in. You can change this later from the tray menu.
  6. Assistail starts: the lion appears on your taskbar and asks “What would you like to call me?”. Type a name (or click Later to keep “Leo”). The orange spark also appears in the system tray.
Tip: to keep the spark always visible, drag it from the ^ overflow area onto the taskbar.

The installer puts the app in %LOCALAPPDATA%\Programs\Assistail, adds a Start menu entry (search for “Assistail”), and lists it in Settings → Apps. If the Claude Code CLI isn't found, the installer shows a warning.

A cartoon lion with a curly mane sits on top of your taskbar, paws on its edge. He's your shortcut to everything. In this guide he's called “your lion”. On your PC he has the name you gave him.

Trick shortcut: press Ctrl+Alt+T anywhere. Each press does the next trick in the list above, then starts over. Choosing a new trick while one is still going interrupts it.

Make him say something: right-click → Make … say something…, type a message, and it appears in a speech bubble above him. Click the bubble to dismiss it.

What he does on his own

  • Random quirks: every 1–3 minutes when you're not using him, he does one of the tricks above, or says a short line in a speech bubble. Change how often under right-click → Quirks when idle (Often / Sometimes / Rarely / Off), and turn the talking on or off with Talks on his own.
  • Idle: breathes, blinks, swishes his tail, twitches an ear.
  • Mouse comes near: perks up.
  • While Claude answers: thinks (head tilted), nods along as the answer streams in, then does a little happy hop.
  • Picked up: legs dangle; plops down where you drop him.
  • Unused for 10 minutes: naps. Move the mouse over him to wake him.
  • Full-screen video, game or slideshow: hides, and comes back afterwards.

He asks Claude to answer as him, so asking “what's your name?” in the chat gets his name back.

Folder awareness

If you press the hotkey while a File Explorer window is in front, the chat header shows that folder (📁). The >_ Claude Code button then opens Claude Code right in that folder. On the desktop, it uses your Desktop folder. Otherwise it uses the last Explorer folder you were in, or your home folder.

Open Claude Code or switch folders by asking

Type these in the chat. They're handled instantly by your buddy, without asking Claude:

You typeWhat happens
open claude hereOpens Claude Code in the chat's current folder (the 📁 chip)
open claude in C:\code\my-appOpens it in that exact path (~ and %USERPROFILE% work too)
open claude in downloads / desktop / documentsOpens it in that folder
open claude in my-app
open claude in the folder in C drive with a name my-app		 Searches for a folder with that name (recent folders, your home and code folders, then your drives). One match opens straight away; several show up as clickable choices; none offers Browse…. Mention a drive (“on D drive”) to search only there.
switch to my-app · go to documents · cd C:\codeChanges the chat's folder without opening anything. You can then ask about the files there.

Click the 📁 folder chip in the chat header for your recent folders, Browse…, or Open Claude Code here. A folder you pick stays until you click New chat. If your buddy can't make sense of a request, he asks Claude to work out the folder name, which takes a few seconds.

Good to know

  • The chat can read the files in its 📁 folder, but never change them or run commands. Ask things like “what does this project do?” or “where is the login code?” and the status line shows what it's looking at. For real work in a project, use >_ Claude Code. To stop the chat from reading files, untick Can read files in the chat's folder under Chat model in the tray menu.
  • The chat pops up on top, and drops behind when you click another window. Clicking your buddy brings it back to the front; clicking him while the chat is in front hides it.
  • The first reply takes a few seconds because each message starts Claude Code in the background. For faster answers, choose Haiku (fastest) under Chat model in the menu or in Settings.
  • Follow-up questions remember the conversation until you click New chat or quit the app.
  • Replies are shown as plain text.

5. Ask about files, the clipboard or the screen

Give your buddy something to look at, then ask about it (“what failed?”, “explain this error”, “what's in this picture?”).

To…Do this
Ask about a fileDrop it on the lion (he perks up while you drag it over him), drop it on the chat window, or click 📎 in the chat → Attach files…
Ask about something you copiedPress Ctrl+Shift+Alt+V anywhere, menu → Ask about the clipboard, or 📎 → Paste from the clipboard. Works with copied text, pictures (screenshots) and files. In the chat box, Ctrl+V with a picture on the clipboard attaches it too.
Ask about part of the screenPress Ctrl+Shift+Alt+S, menu → Ask about a screen area…, or 📎 → Snip an area of the screen…. The Windows snipping overlay appears: drag over the area and the snip lands in the chat.
Open Claude Code in a folderDrop the folder on the lion. (Dropped on the chat window, a folder becomes the chat's 📁 folder instead.)

Attached items show as chips above the message box; click ✕ on a chip to remove it. Then type your question and press Enter (with no question, he just takes a look).

  • Text files (logs, code, notes) up to 100 KB go straight into your message. Bigger ones, up to 20 MB, are read in parts as needed.
  • Pictures (PNG, JPG, GIF, WebP) and PDFs up to 20 MB are looked at by Claude.
  • Other kinds of files (zip, exe, …) and anything over 20 MB get a clear “can't read this” message.
  • Attached files are copied into a private folder for that conversation (%LOCALAPPDATA%\Assistail\attachments), so follow-up questions can look at them again. The chat can only read them. The copies are deleted when you click New chat or quit (and anything left over after a day).

6. Claude Code alerts

Working in Claude Code in a terminal? Your buddy can keep an eye on it for you:

  • When a Claude Code session finishes, he hops happily and says “Done! ✅ my-app” with the first sentence of Claude's answer.
  • When Claude Code needs your permission or input, he jumps and says “🔔 Claude needs you in my-app”.
  • Click him (or the bubble) to jump straight to that terminal window.
  • Several sessions at once? The newest alert shows first, the others follow.
  • No alert shows while you're already looking at that terminal, and an alert goes away when you switch to it yourself.
  • When he's sent away (or a full-screen app is in front), alerts appear as Windows notifications instead.

Setting it up

Right-click the lion → Claude Code alerts → Set up… (or Settings → Claude Code alerts → Set up…). Assistail shows exactly what it will add and asks first. It adds two small hooks to Claude Code's settings file (%USERPROFILE%\.claude\settings.json): when a session stops or sends a notification, Claude Code runs Assistail.exe --notify …, which passes the event to your buddy and exits straight away. It never blocks Claude Code.

  • Sessions that are already running pick up the hooks when you restart them.
  • Show alerts turns the alerts off and on without touching the hooks.
  • Remove from Claude Code takes the hooks out again. If you haven't changed settings.json since, the original file is put back exactly; otherwise only Assistail's two entries are removed. Uninstalling Assistail also removes them.
  • The quick chat's own replies never cause alerts.

7. Right-click menu: “Open Claude Code here”

In File Explorer, right-click any of these and choose Open Claude Code here:

  • empty space inside a folder (opens in that folder)
  • a folder (opens in that folder)
  • a drive, such as C: or a USB drive

A terminal opens with Claude Code already running in that location.

Windows 11: the item is in the full menu. Click Show more options, or hold Shift while right-clicking to go straight there.

The right-click menu works even when the tray app isn't running.

9. Updating

Automatic: once a day Assistail asks GitHub whether a newer version is out. If there is one, your buddy says “Update available”: click him (or menu → Install update) and confirm. He downloads it, checks it against the SHA-256 checksum GitHub publishes for the file, installs it and comes back a few seconds later with all your settings. Nothing is installed without your OK. Turn the daily check off in Settings → Updates; Check for updates in the menu still works any time.

By hand: unzip a new version and double-click its Install.cmd. It closes the running copy, replaces it, and keeps your settings.

10. Uninstalling

Settings → Apps → Installed apps → Assistail → Uninstall. Or run Uninstall.cmd in %LOCALAPPDATA%\Programs\Assistail.

This removes the app, the right-click menu item, the Start menu entry, the startup entry, Assistail's settings, log and attachment copies, and the alert hooks in Claude Code's settings (if you set them up). Nothing else in Claude Code is touched. The .NET Desktop Runtime stays installed (other apps may use it); remove it in Settings → Apps if you like.

11. Troubleshooting

ProblemTry this
The hotkey does nothing Another app may already use Ctrl+Alt+Space. Assistail then falls back to Win+Alt+C or Ctrl+Shift+Space. Right-click the lion: the active shortcut is shown next to Chat with …. To pick a different combination, use right-click → Settings….
No Claude Code alerts Check menu → Claude Code alerts: it should say Set up ✓ and Show alerts should be ticked. Restart the Claude Code session after setting up. Alerts are skipped while that terminal is the window in front. Assistail must be running.
Clicking an alert doesn't bring the terminal forward Windows sometimes refuses to switch windows; the terminal's taskbar button flashes instead. With several Windows Terminal tabs, the window comes forward but not the tab.
“Ask about a screen area” does nothing It uses the Windows snipping overlay (Snipping Tool). Make sure Snipping Tool is installed and copies snips to the clipboard (its default).
The installer says .NET is missing Install the .NET 8 Desktop Runtime (x64) from Microsoft, then run Install.cmd again.
Chat says “Couldn't start Claude Code” or shows an error Open a terminal and run claude. If it isn't found, install the Claude Code CLI. If it asks you to sign in, do so. Then quit Assistail and start it again.
Chat replies are slow A few seconds per message is normal. Choose Chat model → Haiku (fastest) for quicker answers.
“Open Claude Code here” isn't in the right-click menu On Windows 11, look under Show more options. If it's still missing, run Install.cmd again.
The right-click icon looks blank Windows caches icons. Close and reopen File Explorer, or sign out and back in.
The lion isn't on the taskbar He may have been sent away: right-click the tray spark → Call … back. He also hides while a full-screen app is in front.
The spark isn't in the tray Check the ^ overflow area. If it isn't there, start Assistail from the Start menu.
The app won't start on a work laptop Your organization may block apps that aren't code-signed. Ask IT, or use a personal laptop.
Anything else Check the log file at %LOCALAPPDATA%\Assistail\log.txt.

12. Privacy & what it changes on your PC

Your messages

Quick chat sends your messages through the Claude Code CLI to Claude, using your own signed-in account, exactly as if you had typed them into Claude Code. Assistail has no servers of its own and sends nothing anywhere else. Like any Claude Code session, the conversation history is saved by Claude Code under %USERPROFILE%\.claude\projects.

Network

Apart from chat (through Claude Code), the only thing Assistail does online is the update check: once a day it asks api.github.com for the latest release of this project (and downloads it if you choose to install). The request carries no personal information. Turn it off in Settings → Updates.

What gets installed

Assistail is an ordinary app. It doesn't modify Windows, install drivers or services, or need admin rights. Everything is per-user:

LocationPurpose
%LOCALAPPDATA%\Programs\AssistailThe app, icon, this guide, uninstaller
%LOCALAPPDATA%\AssistailSettings, log file, attachment copies (deleted on New chat or quit), and a backup of Claude Code's settings while alerts are set up
%USERPROFILE%\.claude\settings.jsonTwo hook entries for Claude Code alerts (only if you set them up)
HKCU\Software\Classes\Directory\…\shell\ClaudeCodeHere
HKCU\Software\Classes\Drive\shell\ClaudeCodeHere		Right-click menu item
HKCU\…\CurrentVersion\Uninstall\AssistailEntry in Settings → Apps
HKCU\…\CurrentVersion\Run → AssistailStart with Windows (only if enabled)
Start menu → AssistailShortcut

Windows updates won't break it, because it only uses standard, long-supported Windows features. Uninstalling removes everything in the table above.
