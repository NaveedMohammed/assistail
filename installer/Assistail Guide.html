2. Installing

  1. Copy Assistail-2.0.0.zip to the laptop and unzip it: right-click → Extract All…. Don't run the installer from inside the zip.
  2. Open the extracted folder and double-click Install.cmd.
  3. If Windows shows “Windows protected your PC”, click More info → Run anyway. This appears because the app isn't code-signed by a publisher, which is normal for a personal tool.
  4. Answer y or n when asked whether to start Assistail when you sign in. You can change this later from the tray menu.
  5. Assistail starts: the lion appears on your taskbar and asks “What would you like to call me?”. Type a name (or click Later to keep “Leo”). The orange spark also appears in the system tray.
Tip: to keep the spark always visible, drag it from the ^ overflow area onto the taskbar.

The installer puts the app in %LOCALAPPDATA%\Programs\Assistail, adds a Start menu entry (search for “Assistail”), and lists it in Settings → Apps. If the Claude Code CLI isn't found, the installer shows a warning.

3. Your lion buddy

A cartoon lion with a curly mane sits on top of your taskbar, paws on its edge. He's your shortcut to everything. In this guide he's called “your lion”. On your PC he has the name you gave him.

To…Do this
ChatClick the lion. The chat opens beside him, on whichever side has more room. Click him again to hide it.
See all optionsRight-click the lion (the same menu as the tray icon)
Move himDrag him left or right along the taskbar. He remembers the spot.
Send him awayRight-click → Send … away, or type go away / bye in the chat. He turns, stands up and walks off.
Call him backRight-click the tray icon → Call … back, or type come back in the chat. He walks back to his spot.
Rename himRight-click → Rename …. The new name shows up everywhere right away.
Make him bigger or smallerRight-click → …'s size → Small / Medium / Large

Tricks (right-click → Tricks)

TrickWhat he does
Shake headA quick “nope” shake, mane bouncing
JumpBig excited jump with a spin
Stretch & yawnStretches his paws out and yawns
Chase his tailSpins after his tail, then a dizzy wobble

Trick shortcut: press Ctrl+Alt+T anywhere. Each press does the next trick in the list above, then starts over. Choosing a new trick while one is still going interrupts it.

Make him say something: right-click → Make … say something…, type a message, and it appears in a speech bubble above him. Click the bubble to dismiss it.

What he does on his own

  • Random quirks: every 1–3 minutes when you're not using him, he does one of the tricks above, or says a short line in a speech bubble. Change how often under right-click → Quirks when idle (Often / Sometimes / Rarely / Off), and turn the talking on or off with Talks on his own.
  • Idle: breathes, blinks, swishes his tail, twitches an ear.
  • Mouse comes near: perks up.
  • While Claude answers: thinks (head tilted), nods along as the answer streams in, then does a little happy hop.
  • Picked up: legs dangle; plops down where you drop him.
  • Unused for 10 minutes: naps. Move the mouse over him to wake him.
  • Full-screen video, game or slideshow: hides, and comes back afterwards.

He asks Claude to answer as him, so asking “what's your name?” in the chat gets his name back.

4. Quick chat

Click the lion, press Ctrl+Alt+Space anywhere, or left-click the tray icon. The chat opens next to the lion (or in the middle of the screen if he's away). Type a question and the reply streams in.

ActionHow
Send a messageEnter
New line in your messageShift+Enter
Hide the chat (conversation is kept)Esc, the ✕ button, or the hotkey again
Stop a reply that's still coming inClick the ■ button (it replaces ↑ while Claude is answering)
Start a fresh conversationNew chat button
Open Claude Code in the shown folder>_ Claude Code button
Copy part of a replySelect the text with the mouse, then Ctrl+C
Move / resizeDrag the header bar / drag the bottom-right corner

Folder awareness

If you press the hotkey while a File Explorer window is in front, the chat header shows that folder (📁). The >_ Claude Code button then opens Claude Code right in that folder. On the desktop, it uses your Desktop folder. Otherwise it uses the last Explorer folder you were in, or your home folder.

Good to know

  • Quick chat can't touch your files or run commands. Tools are turned off on purpose, so it only answers questions. For real work in a project, use >_ Claude Code.
  • The first reply takes a few seconds because each message starts Claude Code in the background. For faster answers, choose Haiku (fastest) under Chat model in the tray menu.
  • Follow-up questions remember the conversation until you click New chat or quit the app.
  • Replies are shown as plain text.

5. Right-click menu: “Open Claude Code here”

In File Explorer, right-click any of these and choose Open Claude Code here:

  • empty space inside a folder (opens in that folder)
  • a folder (opens in that folder)
  • a drive, such as C: or a USB drive

A terminal opens with Claude Code already running in that location.

Windows 11: the item is in the full menu. Click Show more options, or hold Shift while right-clicking to go straight there.

The right-click menu works even when the tray app isn't running.

7. Upgrading

Unzip the new version and double-click its Install.cmd. It closes the running copy, replaces it, and keeps your settings (chat model, start with Windows).

8. Uninstalling

Settings → Apps → Installed apps → Assistail → Uninstall. Or run Uninstall.cmd in %LOCALAPPDATA%\Programs\Assistail.

This removes the app, the right-click menu item, the Start menu entry, the startup entry, and Assistail's settings and log. Claude Code itself is not touched.

9. Troubleshooting

ProblemTry this
The hotkey does nothing Another app may already use Ctrl+Alt+Space. Assistail then falls back to Win+Alt+C or Ctrl+Shift+Space. Right-click the lion: the active shortcut is shown next to Chat with …. To pick a different combination, use right-click → Shortcuts….
Chat says “Couldn't start Claude Code” or shows an error Open a terminal and run claude. If it isn't found, install the Claude Code CLI. If it asks you to sign in, do so. Then quit Assistail and start it again.
Chat replies are slow A few seconds per message is normal. Choose Chat model → Haiku (fastest) for quicker answers.
“Open Claude Code here” isn't in the right-click menu On Windows 11, look under Show more options. If it's still missing, run Install.cmd again.
The right-click icon looks blank Windows caches icons. Close and reopen File Explorer, or sign out and back in.
The lion isn't on the taskbar He may have been sent away: right-click the tray spark → Call … back. He also hides while a full-screen app is in front.
The spark isn't in the tray Check the ^ overflow area. If it isn't there, start Assistail from the Start menu.
The app won't start on a work laptop Your organization may block apps that aren't code-signed. Ask IT, or use a personal laptop.
Anything else Check the log file at %LOCALAPPDATA%\Assistail\log.txt.

10. Privacy & what it changes on your PC

Your messages

Quick chat sends your messages through the Claude Code CLI to Claude, using your own signed-in account, exactly as if you had typed them into Claude Code. Assistail has no servers of its own and sends nothing anywhere else. Like any Claude Code session, the conversation history is saved by Claude Code under %USERPROFILE%\.claude\projects.

What gets installed

Assistail is an ordinary app. It doesn't modify Windows, install drivers or services, or need admin rights. Everything is per-user:

LocationPurpose
%LOCALAPPDATA%\Programs\AssistailThe app, icon, this guide, uninstaller
%LOCALAPPDATA%\AssistailSettings and log file
HKCU\Software\Classes\Directory\…\shell\ClaudeCodeHere
HKCU\Software\Classes\Drive\shell\ClaudeCodeHere		Right-click menu item
HKCU\…\CurrentVersion\Uninstall\AssistailEntry in Settings → Apps
HKCU\…\CurrentVersion\Run → AssistailStart with Windows (only if enabled)
Start menu → AssistailShortcut

Windows updates won't break it, because it only uses standard, long-supported Windows features. Uninstalling removes everything in the table above.
